# LEEl VPN

LEEl VPN é uma variante não comercial baseada no fork público de [hiddify/hiddify-app](https://github.com/hiddify/hiddify-app).

Alterações: nome visível LEEl VPN, identificador Android `com.leel.vpn`, workflows próprios e painel estático para perfis, mensagens e metadata de atualização.

O código continua sob `LICENSE.md`, incluindo GPLv3 e as condições adicionais do projeto Hiddify. Os releases devem ser produzidos pelo GitHub Actions.
